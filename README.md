# Проект "Виджет финансовых операций"

## Описание:

Проект "Виджет финансовых операций" - Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:mariyakhrustal/myFirstPrj.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.

## Модуль `decorators.py`

Модуль `decorators.py` содержит декоратор `log`, который будет автоматически регистрировать детали выполнения функций,
такие как время вызова, имя функции, передаваемые аргументы, результат выполнения и информация об ошибках. 
Это позволит обеспечить более глубокий контроль и анализ поведения программы в процессе ее выполнения.

### Декоратор `log`

#### Описание
Декоратор `log` используется для логирования информации о вызове функции: её имени, переданных аргументов, и
возвращаемого значения.

#### Пример использования 
```python
from src.decorators import log

@log
def example_function(a, b):
    return a + b

result = example_function(2, 4)
```
## Модуль `external_api.py`
Модуль `external_api.py` содержит функцию, которая читает данные о банковских операциях из JSON-файла, получает данные для конвертации валюты с помощью стороннего API.

## Модуль `csv_excel_reader.py`
Модуль `csv_excel_reader.py` содержит функции, которые принимают на вход данные о транзакциях из CSV- или XLSX-файлов.

## Тестирование 

### Введение 
В данном проекте тестирование проводилось с целью обеспечения корректной работы всех функциональных возможностей.

###  Типы тестирования

### Инструменты тестирования

- Pytest

### Запуск тестов
Для запуска тестов выполните команду:
```bash
pytest
```

### Проверка покрытия кода 
```bash
pytest --cov
```
Чтобы проверить какие строчки кода не покрыты тестами используйте команду:
```bash
pytest --cov src --cov-report term-missing
```

### Структура тестов 
Тестовые файлы находятся в директории tests/ и организованы по функциональным модулям.
